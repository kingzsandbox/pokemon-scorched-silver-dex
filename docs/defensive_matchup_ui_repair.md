# Defensive Matchup UI Repair

Date: 2026-05-29

## Change

Pokémon detail pages now show defensive matchups only. The offensive matchup grid was removed from the Pokémon detail UI.

## Dark Mode Repair

The matchup color tokens were changed from light pastel cells to darker, high-contrast cells that fit the silver/gold/near-black theme.

## Rendered Validation

Checked target Pokémon detail routes. Rendered visible text contains `Defensive Matchups` and does not contain `Offensive Matchups`.
